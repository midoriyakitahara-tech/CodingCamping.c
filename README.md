## Deskripsi
Adventure Camp adalah program console berbasis C buat nyewa peralatan camping. Kamu bisa lihat daftar alat, sewa beberapa alat sekaligus dalam satu transaksi, dan cek riwayat transaksi. Total biaya dihitung otomatis dari harga, jumlah unit, dan lama sewa, plus diskon kalau sewanya lama (10% untuk 3-4 hari, 15% untuk 5 hari ke atas). Setelah sewa selesai, program langsung mencetak struk.
